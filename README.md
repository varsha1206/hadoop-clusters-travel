# 🏨 HotelScraperHDFS

A scrappy little data pipeline that goes from **booking.com** to **big data** real fast.  
Built to crawl, collect, and hoard hotel info from top destinations — all the way into a Hadoop-powered vault.

---

## 🕵️ What It Does

- 🤖 **Scrapes Hotels from Booking.com**  
  Using Selenium to fetch hotel details, ratings, images, and more across popular destinations.

- 🗃️ **Cleans and Organizes Hotel Data**  
  Parses and preps structured info ready for analysis or ML tasks.

- 🐘 **Stores Everything in HDFS**  
  Data is stored and distributed in a custom Hadoop swarm setup (locally or remote-ready).

---

## 🔧 Tech Stack

- **Python + Selenium** for scraping  
- **BeautifulSoup** for HTML parsing  
- **Hadoop HDFS** for distributed storage  
- **Shell scripts** for automation & swarm setup
